# 备案与上线步骤（沿用 www.monster-ovo.cn）

决定（2026-10-19）：官网沿用现有域名 `www.monster-ovo.cn`。先把域名转到公司名下，以长沙半亩晴空信息科技有限公司为主体办理网站备案，
备案号下来后按 [deploy/README.md](../deploy/README.md) 上线。

以下规则核对于 2026-10-19，来源附在每条后面；各省管局的要求会调整，提交前以腾讯云备案控制台的提示和湖南省通信管理局的最新要求为准。

## 一、先弄清楚的几条规则

1. **不能直接"变更"成公司备案，要注销原备案、在湖南重新备案。** 腾讯云支持把个人主体变更为企业主体（账号实名改企业 → 域名实名改企业 → 变更备案），
   但不支持变更备案省份（[变更备案相关问题](https://cloud.tencent.com/document/product/243/19617)、[变更备案](https://cloud.tencent.com/document/product/243/19145)）。
   备案省份以主办单位证件地址为准，企业不能跨省备案（[主体信息](https://cloud.tencent.com/document/product/243/19640)）。
   现有备案是北京的个人主体（`京ICP备2024092535号`，App 备案号 `-1A`），公司登记在湖南，所以只能注销北京的备案，再由公司在湖南提交新备案。
2. **注销之后、新备案通过之前，这个域名不能对外提供服务。** 注销经管局审核通过后，对应网站即无法访问，需要重新备案才能恢复
   （[阿里云：注销后重新备案](https://help.aliyun.com/zh/icp-filing/basic-icp-service/the-cancellation-of-other-units-or-the-shell-of-the-icp-for-the-record)、
   [华为云：注销不可逆](https://support.huaweicloud.com/pi-icp/icp_03_0003.html)）。
3. **湖南要求主体负责人是法定代表人**；网站负责人原则上也是法定代表人，不是的话要提供法定代表人授权委托书
   （[阿里云：湖南管局备案规则](https://help.aliyun.com/zh/icp-filing/icp-filing-regulations-for-hunan)，以腾讯云初审要求为准）。
   营业执照上的法定代表人不是你本人，所以人脸核验、管局核查电话都需要法定代表人本人配合。
4. **域名持有者要与备案主体一致**（[主体信息](https://cloud.tencent.com/document/product/243/19640)）；部分管局规定同一手机号不能用于多个备案主体。

## 二、影响

`www.monster-ovo.cn` 不只是官网，还承载 App 的接口（`/api/`、`/im`）、网页版（`/web/`）、协议页（`/legal/`）、分享与推广链接。
注销期间这些都会受影响，App 和网页版连不上服务器。

App 还没有对公众上线，**现在是做这件事代价最小的时候**：上线后再迁移，就要影响真实用户。建议选一个窗口期集中办理，提前告诉测试人员。

另外，App 备案（`-1A`）和网站备案在同一个北京主体下，注销主体时会一起注销，所以公司的新备案要**同时备案网站和 App**。

## 三、建议顺序（尽量缩短中断）

不影响线上的准备工作全部做完，再注销；注销一生效就提交新备案。

1. **准备材料**（不影响线上）
   - 营业执照、法定代表人身份证；网站负责人不是法定代表人时，准备法定代表人授权委托书和网站负责人身份证。
   - 网站信息：网站名称（初审会给意见）、域名 `monster-ovo.cn`、服务内容（官网：公司与产品介绍；同域名下还有网页版与 App 接口）。
   - App 信息：名称"玉米圈"、Android 包名与 iOS Bundle ID（都是 `cn.wyz.ju`）、签名公钥与证书指纹等（以备案页面要求为准）。
2. **腾讯云账号**：备案要求账号、域名、主体对得上。两种做法选一种：把现有账号的实名认证变更为公司（云服务器、TRTC 等资源随账号一起归公司）；
   或公司另开企业账号，用服务器所在账号生成的备案授权码备案。
3. **域名过户**：在域名注册商把 `monster-ovo.cn` 的持有者改为公司，完成企业实名认证（腾讯云文档："修改域名所有者请联系您的域名注册商"）。
4. **注销北京的备案**：在腾讯云备案控制台注销原主体（网站与 App 一起）。从这一步开始，域名会被拦截。
5. **公司在湖南新备案**：一个订单里备案网站和 App；主体负责人是法定代表人（人脸核验），保持电话畅通接听管局核查。
6. **备案通过后**
   - 官网：备案号填进 `src/content/company.yaml → filings.icp`，然后 `./deploy/deploy.sh` → `./deploy/install-nginx.sh` → `./deploy/smoke.sh`。
   - App：新的 App 备案号写进 ju-mobile `lib/legal/legal_info.dart` 的 `kIcpNumber`，重新导出协议网页并部署后端；应用商店资料里的备案号一起更新。
   - 按属地要求（通常是网站开通后 30 日内）到[全国互联网安全管理服务平台](https://beian.mps.gov.cn/)办理公安联网备案，号码填 `filings.psb`，页脚加公安备案图标。

## 四、另外要确认

- **ICP 经营许可证**：营业执照的许可项目有"第二类增值电信业务"。App 里有付费功能（"请玉米圈喝一杯可乐"）等经营性内容时，是否需要 ICP 经营许可证，
  向湖南省通信管理局或专业人士确认。普通备案不能替代许可证，官网也不会把经营范围写成"已获许可"。
- **协议与运营主体**：备案、商店开发者账号都改为公司后，把 `company.yaml → operator.effective` 改为 `true`。
